# 풍하중 계산 도구

간단한 명령행 풍하중 계산기 `wind_load_calculator.py`를 제공하여 KDS 기준을 참고한 기본 풍압(q), 형상계수(Cp), 중요도계수(Iw), 풍속압계수(Kz)를 적용한 설계 풍하중을 계산합니다.

## 설치 및 실행 전제

* Python 3.9 이상을 권장합니다.
* 별도의 외부 패키지가 필요하지 않습니다.

## 사용 방법

다음과 같이 명령행에서 실행합니다.

```bash
python wind_load_calculator.py --shape rectangular --height 30 --width 20 --length 40 \
  --basic-wind-speed 40 --exposure 교외 --importance 보통 --gust-factor 0.9
```

### 주요 인자 설명

| 인자 | 설명 |
| --- | --- |
| `--shape` | 구조물 형상(`rectangular`, `circular`, `triangular`) |
| `--height` | 구조물 높이 (m) |
| `--width` | 풍방향 유효 폭 혹은 직경 (m) |
| `--length` | 구조물 길이 (m), 필요 시 사용 |
| `--basic-wind-speed` | 설계 기본풍속 V (m/s) |
| `--exposure` | 노출 범주(`도심`, `교외`, `해안`) |
| `--importance` | 중요도 구분(`보통`, `중요`, `매우중요`) |
| `--gust-factor` | 거스트 계수(기본값 0.85) |

## 예시 출력

```
설계 풍하중 계산 결과
============================
항목           | 값     | 단위/설명
---------------+--------+--------------------
기본풍압 q      | 980.800 | kN/m² (0.613·V²)
형상계수 Cp     | 0.80   | 형상별 압력계수
중요도계수 Iw   | 1.00   | 사용자 선택
풍속압계수 Kz   | 1.15   | 노출조건·높이
거스트계수 G    | 0.90   | KDS 41 17 00 참조
유효면적 A      | 600.000 | m²
설계풍압 p      | 812.102 | kN/m²
설계풍하중 F    | 487261.440 | kN
```

> 위 예시는 높이 30 m, 폭 20 m, 길이 40 m의 직육면체 구조물에 대한 계산 결과입니다.

## 참고 사항

* 본 도구는 교육용·개략 검토용으로 작성된 예시이며 실제 설계 시에는 최신 KDS 및 세부 기준을 반드시 확인해야 합니다.
* 풍속압계수(Kz)는 높이 구간별로 단순화된 값이며 사용자가 환경에 맞게 수정할 수 있습니다.
